# Lámpara de Faraday — Presentación web

Sitio estático y responsivo para presentar el funcionamiento del prototipo.

## Archivos
- `index.html`: contenido principal.
- `styles.css`: diseño y responsividad.
- `script.js`: interacciones.
- `assets/circuito_original.png`: esquema original del montaje.

## Probar localmente
Abre `index.html` en cualquier navegador moderno. No necesita instalación.

## Publicar en GitHub Pages
1. Crea un repositorio nuevo.
2. Sube todos los archivos manteniendo la estructura.
3. Ve a **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/root`.
6. Guarda. GitHub te mostrará la URL pública cuando finalice el despliegue.

## Dominio propio
Después puedes configurarlo desde **Settings → Pages → Custom domain**.
